Membership Operator (in)
1. What are membership operators in Python?
--->Membership operators in Python are used to test whether a specific value or variable exists within a data sequence or collection. They evaluate structural presence and return a Boolean value: True or False.
2. Which membership operators are available in Python?---> in and not in
3. What is the purpose of the in operator?
-->The purpose of the in operator is to check if a specific value exists inside a collection or sequence. It performs a search and returns a boolean value: True if the item is found, and False if it is not.
4. What is the output of 10 in [10, 20, 30]?---->True
5. What is the output of 15 in [10, 20, 30]?---->False

	True
7. Check whether a word exists in a sentence using in.
	a =  ['python','javascript','java','c++']
	"c++" in a
	True

9. What is the output of 'z' in 'Python'?----->False
