Identity Operator (is)
1. What is an Identity Operator in Python?
---->An identity operator in Python is used to check whether two variables point to the exact same object in memory.
2. Which identity operators are available in Python?
---->There are exactly two identity operators available in Python.
---->1. is Returns True if both variables point to the same object in memory. Returns False if they point to different objects, even if the values match.
---->2. is not Returns True if variables point to different objects in memory. Returns False if they point to the exact same object.
3. What is the purpose of the is operator?
----->The purpose of the is operator is to determine whether two variables share the exact same memory address
4. What is the difference between == and is?
------->== (Equality Operator): Checks if the values of two objects are equal. It looks at the data stored inside the objects.
------->is (Identity Operator): Checks if two variables point to the exact same object in memory. It looks at the memory address (id()) of the objects

Identity Operator (is not)
1. What is the purpose of the is not operator?
----->The purpose of the is not operator is to determine whether two variables point to different objects in memory.
2. What is the difference between != and is not?
------>!= (Inequality Operator): Checks if the values of two objects are different. It looks at the actual data stored inside them.
------>is not (Negative Identity Operator): Checks if two variables point to different objects in memory. It looks at their unique memory addresses (id()).
